한달치 개인정보처리방침

시행일: 2026년 10월 18일

1. 수집하는 정보

한달치는 개인정보를 수집하지 않습니다. 입력하신 알바 정보(이름, 시급, 근무 기록 등)는 사용자의 기기 안에만 저장되며, 개발자나 제3자의 서버로 전송되지 않습니다.

2. 기기 기능 사용

알림: 근무 기록과 급여일을 알려 드리기 위해 기기 안에서 알림을 예약합니다. 정보가 외부로 전송되지 않습니다.
Face ID: 앱 잠금을 켠 경우에만 본인 확인에 사용합니다. 생체정보는 앱이 접근하거나 저장하지 않으며 iOS가 처리합니다.

3. 백업

백업 파일은 사용자가 직접 공유 기능으로 내보내고 불러옵니다. 파일을 어디에 보관하는지는 사용자가 결정합니다.

4. 추적과 광고

사용자 추적, 분석 도구, 광고를 사용하지 않습니다.

5. 데이터 삭제

앱을 삭제하면 기기에 저장된 모든 기록이 함께 삭제됩니다.

6. 급여 계산에 대한 안내

앱이 보여 주는 금액은 참고용 예상치이며 법적 효력이 없습니다. 실제 급여와 주휴수당은 근로계약과 관련 법령에 따라 다를 수 있습니다.

7. 문의

문의는 GitHub Issues로 남겨 주세요.
